# Katkı Rehberi

- Ücretli/korsan dosya eklemeyin.
- Plugin jarlarını repoya koymayın; resmi indirme linklerini dokümana ekleyin.
- Tüm oyuncu görünen metinler Türkçe olmalı.
- Config değişikliklerinde kısa açıklama ekleyin.
- Java kodu Paper API 1.21.1 ile uyumlu kalmalı.

## Build

```bash
mvn -f custom-plugin/pom.xml package
```
