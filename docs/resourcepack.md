# Kaynak Paketi

`resourcepack/` klasörü tamamen Türkçe isimlendirme ve CustomModelData şablonları içerir.

## Kullanım
1. Klasörü zipleyin: `resourcepack.zip`
2. Sunucu CDN veya web host'a yükleyin.
3. `server.properties` içinde `resource-pack=` alanına direkt linki yazın.
4. ItemsAdder kullanıyorsanız `/iazip` ile üretip aynı şekilde dağıtın.

Not: Bu kaynak paketi özgündür; ücretli ürün assetleri kopyalanmadı.
