# Daha İyi Ücretsiz Sürüm Planı

Public sayfadan görülen fikirler kategori olarak incelendi; özel/ücretli dosya, görsel, metin veya asset kopyalanmadı. Bu proje özgün, Türkçe ve GitHub'a uygun olacak şekilde geliştiriliyor.

## Hedeflenen Üstünlükler
- Tam Türkçe deneyim: menüler, mesajlar, dokümanlar, resourcepack dil dosyası.
- Açık kaynak özel plugin: `custom-plugin/MoonTownyCore`.
- 30 seviyeli oynanış, 500+ saatlik ekonomi eğrisi hedefi.
- 4 RTP dünyası + kaynak dünyası reset operasyon planı.
- Jobs + görev + vote + sezon kasası döngüsü.
- Pay-to-win azaltılmış denge: para, claim ve ödüller kontrollü.
- GitHub Actions ile otomatik plugin build.
- Geyser/Bedrock, dungeon ve RPG addon şablonları.
