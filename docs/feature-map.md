# Özellik Haritası

Bu paket, public sayfada listelenen Towny setup özelliklerine karşılık gelecek şekilde özgün olarak genişletildi.

## Çekirdek
- 4 RTP dünyası: wild, resource, nether, end
- Spawn koruma + hologramlar + NPC komutları
- Towny kasaba/ulus/claim dengesi
- Ekonomi, market, auction, playerwarps
- 24 aşamalı level sistemi
- Jobs sistemi: Miner, Woodcutter, Farmer, Hunter, Fisher, Builder
- Jobs pointshop: tools, keys, boosters, cosmetics, resources
- Skills sistemi
- Vote ödülleri ve vote party
- Crates: vote, royal, seasonal
- Quests: başlangıç, madenci, çiftçi, towny, jobs
- TAB, scoreboard, menüler
- Anti-combatlog ve temel güvenlik

## Addon Taslakları
- RPG Addon: özgün Grinvale bölgesi, NPC görev zincirleri
- Dungeons Addon: 8 özgün dungeon tasarımı + boss/mob configleri
- Geyser Addon: Floodgate/Geyser ayar şablonu

## Lisans Notu
Ücretli ürün dosyaları, assetleri veya birebir metinleri kopyalanmadı. Aynı oyun deneyimi hedeflenerek sıfırdan config paketi oluşturuldu.
