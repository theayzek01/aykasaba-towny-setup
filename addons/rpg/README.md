# RPG Addon - Grinvale

Özgün RPG eklenti taslağı.

## İçerik
- Grinvale Town bölgesi
- 14 NPC rolü: Mayor, Blacksmith, Alchemist, Guard Captain, Farmer, Fisher, Librarian, Miner, Hunter, Merchant, Sailor, Priest, Stablemaster, Cartographer
- 5 bölüm hikaye zinciri
- Günlük görevler
- RPG ödül tokenleri

Dosyalar: `npcs.yml`, `quests.yml`
